## 2. 已确认的接线缺口

1. photo_reference.py:29–32 的 AUTO 会在图片数量符合完整角色组时选择 COMPLETE_LOOK。外部 reference_only 来源不能使用图片数量推断可直接消费的权限。此次任务已经实际冻结为 COMPLETE_LOOK；究竟由具体预设还是 AUTO 进入，应保留该次入口证据，不仅凭数量反推。
2. auto_photo_supply.py:303–306 把 adoption 写在备注和台账；生成输入没有相应消费。备注还可能被 workflow 覆写，不能作为执行合同。
3. photo_content_planner.py 的 complete_look_set 和 workflow 兜底使用“沿用上传素材”。这是旧完整素材流程的语义，不宜全局改成原创生成。
4. 本次冻结输入 travel_place、travel_topic 都为空，未承载日本目的地。当前 workflow 明确读取“旅行地点（可选）”；不能认为飞书存在“旅行国家”字段就代表已经接入。
5. auto_photo_supply.py:313 从 narrowed[0] 取选题，而图片来自 selection.main_note_id；模型终选不是第一候选时，选题和图片串配。
6. _upload_references 只取主笔记前 N 张，未真正消费补充笔记和页级选择结果。选材结果看起来丰富，但生效部分有限。
7. 当前供稿代码用 ProductBrief(product_code, "")，未提供真实商品品类、颜色与版型，指定商品的选材能力不能按方案文字视为已完成。

## 3. 首先修执行路径，保持旧能力

建议先暂停这两条问题任务及相同外部来源路径的自动发布资格，保留现场，不影响人工自有素材路径。本轮未代为执行暂停。

新增最小外部参考合同，字段建议复用已有对象：source_kind、authorization、source_note_ids、selected_pages/hashes、adoption、effective_destination、execution_policy_version。

合同存于持久台账，按飞书 record_id 或稳定唯一引用关联，在 workflow 规划前加载并冻结到输入。不能依赖会被覆写的备注，也不能仅靠可编辑的来源文本充当授权证据。外部来源记录缺合同应在付费前报接线错误，禁止回落 COMPLETE_LOOK。

分流：

- 原有人工完整素材任务：保留既有 COMPLETE_LOOK 行为。
- 外部 reference_only、无商品：进入已有 STYLE 生成路径，消费明确用途。
- 外部 reference_only、有指定商品：商品路径保留商品为权威，第三方只供配套和风格参考。
- narrative_only：使用提取后的内容结构，不将第三方图片送入生图。若现有 STYLE 必须有视觉图片，复用账号人物/自有素材或增加最小描述输入支持，不用无关图片凑条件。

仅把供稿写入类型改为“风格参考”可以减少误路由，但不足以作为最终防线；生产入口还需按来源合同校验。

四选一仍可输出四套搭配和互动文案；需要改变的是源图直接对应成片页的机制，不必增加页数或另建 Recipe。

## 4. adoption 必须改变实际输入

| adoption | 实际采用 | 不采用 |
|---|---|---|
| outfit_only | 单品组合、比例和层次；必要的穿搭参考图片 | 原人物身份、原背景与完整构图 |
| visual_only | 色彩、光线、排版层级的提取结果 | 参考中的商品事实与具体人物场景复刻 |
| narrative_only | 选题和页面作用的抽象结构 | 第三方图片输入、原文案照搬 |
| overall | 综合借鉴上述适用信息，由本篇重新策划 | 不表示整张图或整组页序一比一复现 |

overall 的执行名称可以内部收敛为综合灵感，保留旧值兼容。不再增加运营开关。

Prompt 必须服从实际输入：不采用环境时，不能仍把环境图放进 continuity 通用列表；不采用原人物时，人物依据应来自账号有效人物包。对于场景很强的第三方全图，先用 Doubao 抽象出搭配和摄影描述，减少完整场景图直接输入。

当前图像客户端未见通用 strength/denoise 参数。不要凭空增加固定数值并宣称有效；如某个实际供应商支持，另验证参数语义。当前优先修用途、路由、规划和真实模型请求。

## 5. 旅行地点：先 L1，再轻量 L2，L3 后置

本篇地点来源统一解析：明确的任务地点/国家 > 账号目的地配置；没有就按无明确目的地生成，不假装在日本。账号市场 TH 与旅行目的地 JP 是两个维度，不能共用 target_country。

若国家来自表格隐含默认值，应在任务摘要显示实际采用值及来源；不用增设每篇人工确认。

L1 必做：将目的地写入冻结合同，规划、生图、标题读取同一个值。固定背景可只在内容中讲日本旅行，不需要画日本街景。目的地场景采用目标地点的合理场景；只有国家时，不凭空声称某个具体景点。

L2 轻量补齐：素材分析保存文字明确提供的地点、粗场景类别、是否存在显著地标及未知状态。不用模型猜每张图片精确地理位置。只在“采用环境”时按地点冲突过滤；outfit_only 不应因参考拍摄于中国就排除可用穿搭。

对存量分析做按需补充，保留已有搭配分析缓存，不因加地点字段全库重跑。能从标题/正文提取的先做文字处理。

L3 后置：按日本等目的地定向采集，提高匹配率，但不能解决原图入成片问题，不是本次首要修复。

## 6. 素材筛选和审美 QA 收敛

不要把 poor 摄影和“穿搭不可参考”永久等同。当前已拒绝素材不自动恢复；未来分析区分搭配是否可辨认、摄影是否值得借鉴。摄影较差但搭配清晰的素材可以仅提供文字化搭配信息；只有需要继承视觉质感时才要求摄影质量合适。

不新增每篇人工审核、不堆叠审美评分。现有硬缺陷检查继续使用，普通风格偏好记录即可。新路径先用少量代表样片验证参考是否真正转化为新策划。

泰文等非拉丁文字不能仅凭“看着陌生”判乱码。优先检查程序实际绘制文本、字体和边界；视觉异常需指出具体位置/字符，与最终预期文案核对。转写不确定不等于乱码；明确截断、缺字、字形框或遮挡仍可处理。文字问题重排，不重生穿搭。

## 7. 来源风险与检查边界

按本项目 reference_only 约束，本次四张第三方原图进入成片素材属于应阻止发布的问题，不需要等相似度评分。

不得沿用“原作者投诉几乎必成立”的确定法律结论，也没有改变某个百分比就安全的界限。降低风险的方向是抽象穿搭原则、重新策划和生成，避免复用原图、原文和高度对应的摄影表达；技术措施不等于法律授权。

工程上检查产物谱系：直接用于成片的源资产必须是允许使用的自有/授权资产，或有真实生成记录的新资产；第三方文件可以是生成的参考祖先，但不能成为裁切排版的直接底图。最终文件 SHA 与原图不同不能证明已生成。

先在外部参考任务入生产/资产晋升前实施这条检查，保留发布既有校验。不要借此次修复绕过人工/策略授权设计。

## 8. 开发顺序与验证

第一批：来源合同、拒绝 reference_only 进入 COMPLETE_LOOK、修 selected-note 选题读取、按实际选中页供图。复用正式建行与扫描器，不改定时任务。

第二批：adoption 从冻结输入贯穿规划、参考列表与实际生图；接通旅行国家/地点。指定商品需要先解析真实商品摘要；无法解析则明确不支持该任务，不以空品类冒充验证通过。

第三批：地点轻量补充、非拉丁文字误报处理、代表样片。

必须补充跨层测试，而不只测试选材返回值：

- 外部参考图片数量恰好等于角色数也不能进入完整素材直用路径；手工旧任务行为保持。
- narrative_only 无第三方图片进入生图；outfit_only 不注入原环境；overall 不生成逐页忠实复刻合同。
- 终选第二候选时，图片、主题、页选择均来自第二候选；补充素材只有实际消费才记录为采用。
- 日本任务带川西参考：舍弃原背景，或只借鉴搭配；固定背景无需强制日本景点。
- 实际调用生成器，有可追溯新资产；不能仅检查最终 SHA 不同。
- 更改 adoption、地点或源图片后合同指纹变化；旧任务不静默重用原 staging。
- 商品任务包含真实商品资料并保持款色。
- 正常泰文不能因非拉丁被判乱码。
