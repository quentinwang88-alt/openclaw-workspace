# 图文养号质量与入口优化（2026-09-04）

## 生效范围

新建「TH｜随机养号组合｜轻文字」任务统一使用 `RECIPE_MULTI_LOOK_V1`：拆解首图 + 后续不同穿搭，目标五页、总长 6000 ms。随机性保留在人物、商品参考包与穿搭选择中，不再随机回退到旧十秒配方。显式选择的其他旧预设不被全局改写。

既有批次的冻结计划、已经生成的图片和视频、确认发布、发布队列不迁移。本次不调用生图、不回写正式任务、不改变 BGM 或扫描频率。

## 新计划行为

- 五页时间为 1600 / 1000 / 1000 / 1000 / 1400 ms。可执行穿搭不足时使用实际页数，不为凑五套捏造模板或重复生图。
- 穿搭选择兼顾历史使用次数与裙裤轮廓、鞋型、内搭、配饰的可见差异。相似度仅用于排序，不是新的审核门槛。明确的 `shoes` 字段不得被运动鞋兜底覆盖。
- 工作台在生图前显示冻结后的实际穿搭数、页数、时长；目录预览中的五套是目标值，不冒充实际值。
- 新轻文字方案写入 `overlay_spec.layout_policy=reserved_header_v2`。视频在运动处理后等比缩入剩余画面，顶部预留 240 px；标题用 48 px 深色字。整条视频保持相同画面区域，避免无字幕页突然放大。代价是人物显示高度缩小约 12.5%，不拉伸头身或裁掉脚部；旧冻结字幕样式不变。
- 新拆解图写入 `item_layout_policy=compact_stack_v2`，按透明素材的可见轮廓高度排布单品，固定间隔、保持人物区域与商品比例。
- `item_contrast_policy=soft_silhouette_v1` 只为接近背景色的透明单品加轮廓外柔影，不改变衣服颜色、背景颜色，不画购物截图或伪造价格。
