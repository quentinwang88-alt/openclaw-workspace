# 穿搭拆解模板接入图文养号

## 运营入口

在现有图文养号任务表新建一行：

- 产品编码：目标 SKU。
- 生产预设：`TH｜穿搭拆解首图｜均衡变体`。
- 生成数量：1–9 套。
- 审核方式：`人工确认` 或 `自动审核`；空值按人工确认处理。
- 勾选执行。

穿搭复用当前 Look 模板库。P2 是先生成的完整全身锚点，交付顺序仍为 P1 拆解封面在前。
数量表示整套内容数量，不是单张图片数量。同一行有历史任务时继续使用冻结的输入；更换产品或预设请新建一行。

## 审核与预览

| 审核阶段 | 预览/成片 | 通过后 |
| --- | --- | --- |
| 锚点审核 | 各套 P2 全身图 | 提取穿搭素材、合成 P1、生成 P3–P5 |
| 组图审核 | 当前待审套数的五图 | 根据冻结素材渲染视频 |
| 成片终审 | 实际 MP4 | 标为已验收，允许确认发布 |

人工模式：查看附件后把“审核”改为“通过”。一次确认只批准当前显示的阶段，下一阶段仍待审。
“审核批次”为系统管理字段，请勿填写或修改；它使旧的“通过”不能批准已更换的新素材。

自动模式：初次执行按阶段调用视觉审核。单次模型请求硬截止 120 秒，整组审核预算 600 秒；
超时是服务异常，不能转换为内容通过。已完成单图的审核结果按输入指纹保存，重试可以续用。
自动成片审核检查每个镜头中点与尾部的实际视频帧，覆盖裁切、文字、人物比例、商品一致性和细节镜头角色。
这是关键帧检查，不等同于连续视频运动审查。

审核失败或服务异常：查看备注中的原因，重做指定镜头，或勾选“重试审核”。
需要人工判断时，操作者可看过当前附件后明确选择“通过”。系统不会代替操作者记录人工通过。

## 返工

- 组图或成片阶段选择 `重做P4`：新建 revision，仅更新 P4，再重新组审、渲染和终审；其他已选图复用。
- 选择 `重做P2` 或 `整组重做`：新建 revision，清除锚点及其下游选择，重新从 P2 审核开始。
- 旧成片、旧图和旧审核记录保留。新版本未终审前不能进入发布队列。
- 已排期或发布中的任务不能直接返工，须先处理其排程。

新配方 P4 使用从颈部到大腿上段的商品主体取景，抑制美妆自拍与过度磨皮；
通用变体机位不能覆盖该角色约束，渲染不再使用向上放大的 `upper_body_focus`。
历史任务仍以已冻结的计划为准，不会因升级配置静默改变。

## 发布

仅当当前 revision 的实际成片通过终审，任务才显示“已完成”。随后勾选“确认发布”，
沿用已有主排班入口。母版保持无声，BGM 在发布阶段选择。

## 安装与检查

`scripts/ensure_feishu_task_table.py` 幂等补充字段与预设选项。
`scripts/run_feishu_tasks.py --dry-run` 只检查触发动作，不生成、不审核、不发布。
现有 `com.likeu.opv-feishu-scanner` 每 120 秒读取当前代码，无需新建另一个调度任务。
