## 关键发现

### 1. 新视觉预设仍未控制实际渲染（高优先级）

`services/photo_package.py:208–280` 的 `_draw_overlay` 仍处理单个字符串：按现成换行分段、统一居中、宽度不足则逐级缩小字号、绘制圆角背景。不支持独立的标题/正文/CTA 层级，也不消费预设排版引用。

`config/layouts/PHOTO_TRAVEL_CARD_V3.json` 仍固定 top_offset=120、居中浅色底框、末页深色 CTA。三类背景换了，但文字系统未换。

修复：完成已约定的 structured renderer 和明确路由。新 manifest 应记录实际执行的 layout 版本；显式新排版不能静默使用旧模板。旧任务继续走原模板，避免全局替换。

### 2. 字体实际回落，整段缩字进一步破坏层级（高优先级）

`photo_package.py:75–90` 按存在性选择首个可用字体。模板首选 `/System/Library/Fonts/Thonburi.ttc` 在本机不存在，第二项 Arial Unicode 可用；本地按当前模板解析结果为 Arial Unicode MS Regular。

没有独立标题字重，标题与地点使用相同字体与层级。相同封面规则下，三条文案实际计算字号分别为旅行 64、纯色 60、室内 54；字号由句长决定，难以形成账号统一的视觉节奏。内页“B · 搭配名称 — 解释”全部挤在一行，38px 字体在手机缩略显示下显得细小。

修复：使用随项目部署、明确支持泰文的字体及标题/正文两种字重，记录实际字体标识。先用真实泰文验证字形与排版，不直接照搬中文参考图字体。新模板按语义块断行，标题字号保持稳定，先调整行数与文字区，再有限缩字。

### 3. 文字区域与人物构图未协调，另有 bbox 偏移问题（高优先级）

纯色封面第二行文字压到头顶；现有 travel_final_page_qa 已给出 subject_obscured=true、passed=false。不能把成片文件已经导出等同于最终通过，也不应为通过而取消遮挡检查。

`photo_package.py:255–278` 通过 bbox 的高差计算背景尺寸，但绘制文字时未补偿 bbox 的顶部偏移。例如本地复算纯色封面 bbox=(0,18,1001,142)，底框下沿为255，而文字实际墨迹到262；室内封面也有类似偏移。这解释了部分文字贴底甚至越出浅色底框的现象。

修复：文字定位与底框使用同一实际墨迹边界；将本篇文字区与主体区域传给生成/渲染。当前源图先通过调整文字区、换行、局部版式处理，避免重生。纯色背景已有足够清洁空间，不需要默认再套浅色横条。只在复杂背景确实影响可读时使用局部底色。

### 4. 上轮其他关键断点尚未全部关闭

- 背景 kind、摄影基准与冻结配置已经接到部分执行路径，固定背景 QA 的成功短路已修。
- `services/photo_reference_vision.py:1153–1159` 的结构重试归一化仍漏传 fixed_background，首次和重试可能采用不同场景判断。
- `services/photo_theme.py` 的 native_multiway 与 `services/feishu_workflow.py` 的 travel_theme_type 判断仍未打通正式主题文案链路；不能把这次三组温度样例当作一衣多穿验收。需要补专门的一衣多穿样例。
- `services/photo_style_reference_supply.py:401–408` 仍将 ENVIRONMENT 用途图片加入通用 continuity_reference_images；固定背景清空专用环境字段并不等于过滤实际图片输入。下一步只过滤固定背景下“仅环境用途”的图片，多用途图保留有效价值。本批背景正确说明改善有效，但不能据此认为参考用途隔离已经完全完成。

以上应继续按照上轮交接方案完成，不再另建业务概念或增加运营配置。

## 下一步建议：先做同图排版样张，再接回生产

1. 从本批纯色和旅行源图各选一套，用真实最终泰文进行排版验证，不再先批量生图。
2. 做两个表现变体，共用一个 renderer：简洁背景用直接文字与清楚层级；旅行背景用适配留白的文字，必要时加局部对比底色。不是两条业务流程。
3. 封面将地点作为小一级信息，将真正问题作为主标题；内页将搭配名称与一句理由分开。末页 CTA 次级呈现，不横跨鞋履展示。
4. 同时验证封面、内页、末页及手机尺寸下的可读性。完成样张后固化模板配置，再接入已有视觉预设。无需新增每篇人工审批。
5. 新 renderer 的输入继续来自最终文案，中文翻译使用同一份实际绘制文本。中文系统本轮不重建。

不建议只改字体名称、缩短所有文案或增加审美评分门禁。这些都不能补上实际缺失的版式层。
