# 长视频中央口播 V9 实施说明

## 目标

解决四类已经在真实任务 `LFJ_40AEA8CBCB98646F3D48` 中复现的问题：钩子只有抽象标签、写作材料被标准化摘要覆盖、拍摄观察被写入口播、分段时长推动重复总结。

## 已实施

1. 中央引擎新增 `services/spoken_writer.py`。完整上游合同继续供后处理校验；生成模型只收到 `spoken-writer-input-v1`。
2. 同一 `source_argument_id` 的映射结果合并成一份材料。主卖点优先使用人工原文；多主题支持卖点只投影当前选中语义，防止同编号其他主题回流。
3. 明确的正面展示、背面观察、取景任务从口播可选商品描述中排除；具体商品结构保留。
4. 结构原型与本土语言样本独立检索。语言样本可以来自未入选的结构簇；同市场同细分类目优先，同表达类目可作为语言节奏回退。
5. 长视频显式允许跨钩子的人工批准样本作为修辞节奏参考，不能覆盖本条钩子。人工中文参考和本土语言参考在模型输入中分开标注。
6. 写作模型接收全片时长和各段可用秒数，不再接收每段90%–96%的文字配额。已有A/B/C输出结构保留。
7. Edge TTS实测、一次修订和最终混音保持原流程；只有真正过短或过长才修订。可接受时长内不按距93%的远近换稿。
8. 输出记录写作策略版本、模型可见输入哈希、选中参考ID及被排除的拍摄观察，便于定位“库里有但没用”的问题。

## 兼容边界

- 新策略只由 `creative_longform_single_v1` 启用；其他中央口播合同原样透传。
- 15秒原创、人工上传口播和视频生成流程不增加模型调用、质检或重试。
- 已冻结任务的普通 resume 不自动重写口播；新任务或 replan 使用新输入版本。
- 本轮不新增飞书字段或数据库表。

## 验收依据

- 中央引擎全量离线测试通过。
- 原创长视频相关测试通过。
- 真实历史任务只读重放时，人工原文进入模型投影；“正面上身效果”和“背面肩背与衣长落点”被记录为 `FILMING_OBSERVATION_ONLY` 并从口播材料排除。
